## 💻 Lancer le Projet en Local

```bash

npm install

# Démarrer le serveur de développement
npm run dev
```

Ouvrez ensuite [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## ☁️ Déploiement sur Vercel (1 Clic)

1. **Option 1 via GitHub :**
   - Créez un dépôt sur votre compte GitHub (ex: `cablage-cctv`).
   - Poussez ce dossier sur votre dépôt :
     ```bash
     git add .
     git commit -m "Initial commit - Landing page Amine Ait Yahya"
     git push origin main
     ```
   - Connectez-vous sur [vercel.com](https://vercel.com).
   - Cliquez sur **Add New... > Project**, sélectionnez votre dépôt GitHub.
   - Vercel détecte automatiquement Next.js. Cliquez sur **Deploy** !

2. **Option 2 via Vercel CLI :**
   ```bash
   npx vercel
   ```
